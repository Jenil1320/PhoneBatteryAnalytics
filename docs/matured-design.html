Changes in this pass: removed the coloured left-edge rails on cards (a cleaner card carries the charge/discharge state with a chip and coloured value instead), and added the Trends screen — cycles, temperature, voltage and current, each over time with a day / week / month toggle, faint grid and an emphasised endpoint.

The simSES angle: the modeled SoH runs a semi-empirical aging model — calendar fade scaling with √time, an Arrhenius temperature factor and a charge-level stress factor, plus cyclic fade from depth-of-discharge and cycle throughput — parameterised by the exposure data the Pixel already records (swelling_data = hours at each temperature/charge level, and the cycle-count distribution). The household-storage degradation approach, pointed at a phone cell.

Nav: Now · Health · Trends · History (four tabs); the degradation model opens from the Health screen, and estimated app drain sits under History. Build order: Health (2a) + model (2b) → Trends (2d) → Now/endurance (2c) → History/sessions (2e).
